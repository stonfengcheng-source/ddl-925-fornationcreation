# 数鉴 v6 产品结构

工作台主要提供新建治理任务、新建训练实验、查看资产和任务记录。演示启动会幂等登记内置数据，但不会自动创建治理或训练任务。用户选择数据、查看样本、选择治理模板并明确启动；历史任务恢复时以任务实际来源为准。

平台内置两类独立合成数据：教育问答治理数据，以及带显式任务标签的教育文本分类数据。治理来源与数据库资产共用 ID；同一示例的历史来源在资产视图聚合，相关版本仍保留。治理版本可直接进入训练实验，不支持把无标签问答自动变成分类数据。

训练实验提供轻量监督分类和大模型微调两条路线。前者使用字符级 TF-IDF 与 Logistic Regression，适合无 GPU 的中文文本基线；后者保留既有 SFT/LoRA 及评测入口，受实际模型、环境和许可前置条件约束。轻量模型的成绩不代表大模型收益或 Proxy 证据。
