# 从首次使用到模型实验

安装后端和前端基础依赖后，使用 `scripts/start_demo.ps1` 启动本机平台，以 admin 登录。工作台选择“新建数据治理任务”，查看数据并配置规则后由用户点击“开始治理”。进入质量分析查看统计和问题样本；如有待复核记录，在人工复核完成决策及复检，再查看版本和下载文件。统计来自每次运行，合成数据不作为真实 EduChat。

真实数据可在数据治理的“导入已有研究数据”登记本机文件和清单，或通过“导入新数据”上传。来源和许可未经核验时不会自动准许发布。导入后选择数据、验证、应用治理模板并启动；完成后前往质量评价和版本交付。候选版本可带着版本 ID 进入训练实验并生成训练配置，无需再次上传。

实验页优先选择数据与模型，再配置训练和评测。训练、评测条件不足时会阻止启动。评测配置与试运行不等于正式评测成功。浏览器交互与视觉验收本轮未执行。
