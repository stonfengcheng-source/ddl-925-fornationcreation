# 功能审查与第二轮代码状态

审查范围：第一轮 `data_pipeline`、第二轮新增的来源适配、FastAPI 数据路由、React 数据处理页及现有测试证据。工作区原有改动均保留。

## 已落地的代码能力

- 官方来源：保留固定 revision 和许可核验；支持 Hugging Face datasets-server 稀疏行采集，可通过 CLI 选择 200 或 5,000 条。采集请求带 revision；抽样固定随机种子，记录候选 offset、样本 ID、字段结构及 SHA-256。网络未通，尚无真实行数据。
- 文件导入：流水线支持 JSONL、JSON 对象/数组及带 `datasets` 可选依赖的 Parquet；来源清单可对输入文件 SHA-256 做复核。文件哈希一致只说明文件未变，不等于来源、许可或 revision 已官方验证。
- 对话转换：`sequence` 的完整字符串列表按问答对读取，最后一轮作为目标，之前轮次保留在 context；不完整轮次不导出。系统提示留在独立字段。
- 处理流水线：保留 schema、清洗初筛、完全/归一化/近似去重、隐私替换与残留复检、五维质量画像、待审队列、报告与 manifest。近似重复仍由第一轮 SimHash 原型实现，标记复核而不自动删样本。
- 五维指标按命题书口径汇总：完整性主指标为“满足全部必填字段的样本数 / 检查样本数”；一致性包含 schema/题答冲突，并把纯文本无跨模态配对、无独立双人审核标为 N/A；多元性使用配置类别覆盖、分布熵、近重复与长尾指标；无偏性无参考分布时为 N/A；时效性无有效发布日期时不推断过期率。
- 后端路由：新增 `/api/preproject-data`；使用现有登录用户与 buyer/admin 角色，上传和任务文件按用户隔离。结果下载使用文件白名单，不提供原始数据下载。
- 前端：新增 `/app/preproject-data` 页面，连接目录、官方采集、上传、校验、任务状态、取消/重试、统计、五维指标、待审元数据和结果下载 API。

## 未达到验收的功能

- 没有 200 条或 5,000 条真实 EduChat 样本，不能生成真实数据版 `processed.jsonl`、`statistics.json`、`quality_report.md`、`dataset_manifest.json`。
- Data-Juicer 与 Presidio 未接管现有逻辑。当前中文 PII 规则只属于初筛，不能对外承诺识别准确率或脱敏安全保证。
- 当前正在运行的 FastAPI 与 Vite API 代理对 health、模块四状态和预立项目录/来源/任务 GET 均返回 200；仅完成只读联通检查。认证隔离、上传、任务处理、取消/重试和下载未做端到端验收。
- 模块四的训练环境状态接口报告训练依赖缺失，因此当前可访问后端不等于训练功能可运行。
- 服务使用单进程线程池；进程重启时未完成任务会标记失败，不能跨进程续跑。此设计不适用于多 worker 部署。
- 问题样本页面只显示脱敏后的元数据和原因，不展示样本文本；避免未经残留检查的数据内容进入浏览器。
- 质量画像中的类别分布仍由配置关键词推断；无偏性缺参考分布时为 N/A，时效性依赖发布日期字段。质量分数不代表训练效用。
- 用户手动导入的声明不会升级成官方来源/许可核验；许可未核验或未明确授权再分发时，manifest 不会将版本标为可发布。

## 关键代码位置

- `data_pipeline/source.py`：官方来源核验、采样和 `datasets` 可选适配。
- `data_pipeline/schema.py`：EduChat 多轮序列转换。
- `data_pipeline/pipeline.py`：多格式输入、处理流水线、进度与取消检查。
- `backend/app/api/preproject_data.py`：来源、采集、任务、结果与下载路由。
- `frontend/src/pages/PreprojectData/index.tsx`：数据处理用户页面。
