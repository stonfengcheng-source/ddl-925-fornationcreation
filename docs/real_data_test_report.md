HTTP 实际执行了导入、验证、预览、创建任务、状态与结果查询、版本、处理前后样本查询、结果下载及下载文件哈希核对；错误参数返回 400，未授权发布返回 409，缺失文件返回 404。独立 TEST-ONLY 夹具验证了审核确认、编辑复检、版本比较、取消和失败重试。记录见 `evidence/http_results.json`，复现脚本为 `scripts/preproject_http_check.py`（需要自备 200 条输入及后端依赖）。真实 200 条没有人工复核问题，夹具不混入真实统计。

第九轮还验证了 TEST-ONLY 初始化与任务执行、阶段钻取、审核版本号冲突 409、审核后的样本对照与五维版本比较、不可信 Origin 和伪造 Host 的拒绝，以及 API 和新生成下载元数据不包含本地绝对路径。独立正式认证模式下未登录下载返回 401（`evidence/auth_results.json`）。复核重建失败和恢复使用隔离的后端测试夹具模拟；未做长时间跨进程压力测试。

`evidence/` 中统计、指标、报告及清单由真实结果生成；为保护本机位置已删除或替换本机路径，因此经处理的证据文件自身哈希与原件不同。原结果中列出的源数据和产物摘要为运行时记录；完整输入和结果数据未打包。输入文件及来源清单应由有权用户自行放入 `data/preproject/incoming/200/` 后运行命令，不能把未核验来源视作授权发布。
