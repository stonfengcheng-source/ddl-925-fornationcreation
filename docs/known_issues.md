# 已知问题

- 未启动浏览器：六个地址、响应式视觉和完整点击流程没有实际浏览器验收；组件测试和 HTTP 测试不能代替它。
- 页面 loading 骨架和移动端细节仍需完善；处理监控使用现有合并阶段及阶段日志，而非八个完全独立计时的后端阶段。问题类别使用可筛选的分类卡片；raw 版本缺少质量及内容记录时无法比较。
- 审核使用任务级操作系统文件锁和版本号检测并发，复检失败可重试；现有任务执行器仍为单进程内存线程池，不应视为分布式队列。故障恢复、跨平台及高并发压力仍需进一步验证。普通对照只提供经过规则脱敏的规范化来源，不显示原始敏感内容。
- 来源 revision 和许可证均未独立核验，不能正式发布。未读取业务命题书原文。规则脱敏不能保证检测所有 PII。
- 包不包含完整真实数据、安装目录或数据库。离线重现 200 条需自行提供有权使用的输入及清单；Parquet 需安装项目所需的可选依赖。
- Windows 上路径嵌套过深可能触及系统路径长度限制；审核样本 ID 文件名已缩短，建议将项目解压到较短路径。
- 本地免密模式仅供本机演示；正式部署需要密码认证、独立密钥及显式 CORS 配置。测试通过不代表已完成生产安全评估。

- 未经隔离浏览器测试授权，未执行浏览器实操及 1280/1440/1920 视觉验收。
- 当前训练依赖、模型、评测环境及题库未就绪；没有执行真实训练或评测。数据训练授权核验流程尚未实现，未核验版本会被后端阻止训练。
- 环境资源页可检查状态和登记本地模型；创建虚拟环境、持久化多个环境配置、安装引导中的完整自动化及 CUDA 安装修复尚未实现。模型文件存在性检查不证明可加载。
- 已将治理来源与数据库资产用同一 ID 关联；其他旧资产未自动转换为可治理的数据文件。训练实验持久化对象、资源成本及跨实验真实结果对比未完成。
- 教育和通用模板目前共用基础规则参数；尚无完整训练模板预算、模型许可独立核验或自动评测配置生成流程。配置生成与训练成功必须区分。
- 基础上传的来源许可若不满足本地处理策略，记录可能被隔离；高级设置中的来源声明不会自动转为已核验授权。

# 第十二轮限制

- 未获得隔离浏览器测试授权，未运行浏览器实操和不同桌面宽度的视觉验收。治理复核与版本等页面仍有未统一的原生控件。
- 默认演示与 CPU 治理已验收；训练需要具备模型、依赖、硬件及可核验的数据授权。独立训练环境创建向导和数据训练授权核验流程仍未完成，未运行模型训练或正式评测。
- 来源许可未知的真实数据可能被隔离，须核验处理许可。示例数据不作为科研实验结果或发布数据。
- 前端构建仍有大体积资源提示；Markdown 表格、列表和代码块支持 GFM，数学公式目前没有专用数学排版插件。

# 第十三轮限制

- 分类结果只验证合成数据上的轻量监督基线，不能证明 LLM 微调效果或 Proxy 有效性；原大模型训练及评测仍需模型、GPU 依赖、题库及授权，未实际运行。
- 轻量虚拟环境默认复用基础环境的已安装包（独立解释器及进程，但非完全独立依赖副本）；全新离线机器需事先准备兼容依赖。实验管理为单进程工作队列，服务重启中断运行中的实验并标记失败。
- 未经隔离浏览器授权，没有实操、视觉及响应式验收；部分历史治理页面仍有原生控件，整体视觉一致性尚不能宣称完成。
- 自动标签核验仅检查标签字段及任务类型，不能证实用户标签的专业正确性；当前真实数据的训练授权核验工作流尚未实现。
