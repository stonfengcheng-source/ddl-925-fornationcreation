# 新增功能前端审查

审查范围：数据筛选与模型验证（模块四）和预立项数据处理。检查方式包括组件/API 代码审查、定向组件测试、生产构建及对本机现有服务的只读请求；没有操作浏览器或 Edge。

## 功能拆分

- 模块四拆为“数据准备”“模型训练与合并”“统一评测”“结果与错误样本”四个页签。全局任务状态和进度保留在页签上方。
- 预立项数据处理拆为“数据源管理”“任务执行”“结果与报告”三个导航面板，避免来源登记、任务参数和质量报告堆在一屏。
- 数据来源不再预填为 EduChat；导入者填写的来源、许可和版本会明确标为声明。上传文件显示大小/格式约束，处理结果缺失时呈现空状态。
- 模块四清楚标示内置小样本为合成演示数据；训练环境不可用时解释缺失依赖，错误状态显示任务失败信息。

## 发现并修复

1. 桌面模式此前将平台 API 请求发往 8765 本地节点服务，导致模块四和预立项页面无法访问正在运行的 FastAPI。现使用独立的平台 API 基址，默认 `http://127.0.0.1:8000/api`，同时保留环境变量覆盖。
2. 模块四页签延迟挂载表单后，切换页签会卸载字段；旧状态更新方式可能丢失未挂载配置。现对配置增量合并，测试覆盖跨页签配置保留。
3. 预立项页头原称“管理 EduChat 本地数据”，但页面也允许导入其他声明来源的文件；文案已改为通用数据来源表述。

## 验证与边界

- 定向前端测试 22/22 通过：模块四 17、预立项 2、运行环境 3。
- 本机健康接口、模块四状态、预立项目录/数据源/任务接口，以及 Vite 代理对应 GET 均返回 HTTP 200。
- 状态接口显示暂无预立项数据源与任务，且训练依赖缺失；不能据此声称真实数据处理或训练成功。
- 用户明确限制访问 Edge，因此没有浏览器截图或视觉布局验收。完整全项目测试未在本轮运行。
