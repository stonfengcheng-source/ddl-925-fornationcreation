# 平台资源与环境

资源页展示 CPU 治理、训练、评测、治理模板及模型配置状态。平台内置合成示例，含重复、冲突和脱敏案例；不代表真实数据或实验证据。教育问答和通用文本模板复用同一基础规则引擎，支持问答、多轮和指令 JSONL；普通 TXT 按非空行读取，JSONL 可使用 `text` 字段。普通文本不能直接作为问答微调数据。

本地模型可在资源页登记；服务检查配置、权重和分词器文件是否存在，但这不是加载或推理成功的证明。登记时许可状态为待核验或用户声明，非平台独立认证。模型文件不在交付包中。

训练和评测必须使用与平台后端隔离的环境。准备方法：创建独立 Python 虚拟环境，按 `scripts/module4/README.md` 和各依赖项目的安装说明安装适配本机的 PyTorch、训练框架或 OpenCompass；自行提供有权使用的模型和题库。完成后在资源页检查训练环境，在实验页检查评测资源。平台不会自动下载大模型；评测依赖安装操作要求显式确认。当前资源页不负责创建虚拟环境，环境路径仍可在实验高级设置中配置。

显卡可被驱动发现不代表 PyTorch CUDA 可用。评测题库检查仅检查目录与文件存在；实际科目完整性需进一步通过试运行确认。系统目前没有完整的数据训练授权核验流程：未核验的候选版本可生成配置，但训练被阻止。
