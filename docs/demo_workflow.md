# 默认演示与数据边界

平台示例由 `scripts/generate_governance_example.py` 生成，随包提供 JSONL 和 SHA-256 文件。内容均为合成记录，包括多轮、格式清理、重复、近重复、合成隐私测试及需复核的问答。它不代表真实 EduChat 或科研结论。初始化检查哈希、记录结构及样本 ID，存储到当前演示账号的资产中；原始研究数据与其独立。

治理通过 CPU 进行结构检查、清洗、重复检测、隐私脱敏与残留复检、五维评价和导出。质量页面显示真实结果和不可测原因，提供样本对照、复核、版本及报告下载。完成治理不代表内容专业正确或允许正式发布；训练及评测为另行准备的可选能力。
