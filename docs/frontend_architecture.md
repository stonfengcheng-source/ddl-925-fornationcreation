# 预立项工作台前端结构

入口为 `/app/preproject-data`，工作台使用六个业务地址：`sources`（导入和预览）、`pipelines`（规则和提交）、`tasks`（任务和日志）、`quality`（质量与样本）、`reviews`（复核）、`versions`（版本与下载）。左侧主导航只有一个工作台入口。六个页面位于 `frontend/src/pages/PreprojectData/pages/`，共同布局仅持有 URL 数据源、任务和导航上下文；各页面分别管理自己的数据和交互。

URL 查询参数 `source_id`、`task_id` 在导航和刷新时保留；历史任务选择会同步来源。配置项保存在当前浏览器会话，任务参数持久化在后端任务记录中；会话存储不是跨设备配置版本库。没有被选中的数据或任务时显示空状态。完成任务并不代表发布：页面由后端准入结果提示许可及来源状态。

质量页从真实任务统计、指标和脱敏样本接口取数，阶段吞吐量与终态分流分开；类别事件可能重叠。版本比较按样本 ID 查询。前后对照的来源侧已标准化及脱敏，不展示未经授权的原始 PII。浏览器视觉与完整操作尚未验收，不能以组件测试代替。

`useResource` 对质量、报告、审核、历史和版本独立加载；最多进行两次有限退避重试，支持手动刷新并在卸载或任务变化时通过 AbortController 取消请求。结果与任务 ID 绑定，不同任务不能共用旧结果。指标值按指标语义格式化，缺失值保留 N/A。
