# 新增功能前端优化报告

## 改动

- 将模型验证的四组操作按工作顺序放入页签，并保留常驻任务状态、训练环境提示和失败详情。
- 将预立项的来源、任务、报告拆分为三个面板；分别显示加载/空结果/错误状态。各 API 并行刷新时采用独立结果处理，单接口失败不会遮蔽其余面板。
- 在预立项上传入口校验扩展名和 100 MiB 上限，要求来源声明字段；重置文件选择器，限制重复操作，并补充取消、重试的忙碌状态。
- 在模块四训练/合并动作前提示训练环境依赖状态，避免因无训练环境而误以为任务正在运行。
- 修复桌面模式平台 API 基址；修复页签卸载造成模型配置丢失的问题。
