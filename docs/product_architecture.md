# 数鉴产品结构

工作空间保留工作台、任务大厅、发布任务和我的任务。数据建设依次提供我的数据资产、数据治理与质量评价、训练实验与效果验证。平台管理提供运行环境与资源、质量规则、推荐任务和边缘节点，并保留隐私预算、个人中心及管理员功能；具体可见性沿用角色权限。

一次数据建设从登记资产开始。治理来源的 ID 同时是数据库中的资产 ID；治理任务和版本以来源 ID 关联，训练配置以用户隔离的候选版本 ID 及文件哈希关联。已有其他类型的资产仍保留，不能假定已具备可直接读取的治理文件。历史来源未自动迁移或重写；可在数据治理中重新登记已有研究文件。

治理使用 CPU 执行，训练和评测为可选资源。当前训练任务管理仍为单进程状态，尚无持久化实验对象、成本记录或真实实验对比闭环；工作台对无法统计的实验数量显示“—”。
