# 第十四轮交付与复现

## 本地启动

安装 `backend/requirements.txt` 和 `frontend/package-lock.json` 对应依赖，随后在项目根目录运行 `powershell -ExecutionPolicy Bypass -File scripts/start_demo.ps1`。脚本只监听本机，首次启动会校验内置合成数据的哈希与分类标签，并通过真实治理流水线生成一次可复用的分类候选版本；不会自动训练。登录页用户名为 `admin`，本地演示无需密码。停止使用 `scripts/stop_demo.ps1`。轻量训练需要独立环境，环境未就绪时界面会阻止训练并指引准备。

数据治理页面选择合成演示数据并启动治理；也可以导入用户拥有的 EduChat 文件。质量分析可查看规则命中、脱敏前后对照、五维指标、最终认定和报告。版本与交付页展示当前任务实际处理文件、合格候选文件和预览。训练实验中新建实验默认选择已验证的合成分类候选版本，由用户主动启动真实训练。

## 验证记录

交付包 `evidence/baseline_acceptance.json` 记录独立数据库初始化、幂等复用、合成治理、复核后交付以及本轮真实训练。`evidence/baseline/` 中的模型、评测结果、预测与日志只来自合成分类数据。`evidence/functional_results.json` 记录单独的 200 条 EduChat HTTP 回归和数据版本关联，包内不包含其原始内容。两个数据集的统计互不合并。

代码及可重复验收入口：`scripts/baseline_http_acceptance.py`、`scripts/module4_functional_check.py`、`data_pipeline/tests/` 和 `frontend/src/pages/PreprojectData/`、`frontend/src/pages/Module4/` 下的组件测试。真实 EduChat 回归需要本机具有相应合法输入文件。

本轮自动化：前端完整 Vitest 76 项通过；流水线、审核与轻量训练后端定向测试 23 项通过；TypeScript 类型检查和前端生产构建通过。构建提示主包体积偏大。合成数据 HTTP 验收覆盖分类版本准备和复用、34 条治理样例、审核后文件切换、真实模型拟合、模型重载与预测复现、用户隔离及服务重启。独立的 EduChat HTTP 回归覆盖 200 条治理、预览与候选下载、报告及模型验证数据版本关联。完整运行步骤和指标以两个 JSON 证据文件为准。

启动和停止脚本已在单独目录及本机端口下实际运行；默认候选版本准备成功，启动未自动训练。若自动准备失败，服务仍保留启动，训练页可使用“准备基础训练数据”重试。交付包需独立解压后依照依赖声明准备环境，验证使用本机已有依赖，未测试全新机器联网安装。

## 限制

本轮未操作浏览器，也未对 1280、1440、1920 像素布局进行实际视觉验收。网页组件测试不等同于浏览器实操。工程质量筛查不认证答案的专业正确性，不授予训练、再分发或发布许可；无证据时相关状态保持待核验。案例对照的来源侧经过规范化和脱敏，不展示敏感原文。轻量基线仅是合成数据上的监督分类实验，不是大模型训练或正式评测。
