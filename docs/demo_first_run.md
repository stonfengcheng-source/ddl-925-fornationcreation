# 默认演示首次运行

在 Windows 安装基础后端依赖 `python -m pip install -r backend/requirements.txt`，并在 `frontend` 运行 `npm ci`。项目根目录运行 `scripts/start_demo.ps1`；使用工作台地址、admin 本地免密登录。启动脚本使用本机地址、独立演示数据库和存储，并调用明确的初始化操作校验及登记平台示例；初始化失败会报告错误。生产环境不会自动创建示例。

点击“新建数据治理任务”，查看已选数据及样本，进入治理配置并由用户点击“开始治理”；完成后可查看质量分析与版本。分类基线应选择带标签的教育文本分类数据，经治理后在训练实验中创建任务。内置数据为合成数据；基础治理不需要 GPU、网络、用户上传或填写路径。停止使用 `scripts/stop_demo.ps1`；重启复用已登记数据和历史任务。
