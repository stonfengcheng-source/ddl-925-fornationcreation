# 政务领域合成演示语料（任务二输入样例）

- **来源**：本地合成政务问答演示数据，覆盖社保 / 公积金 / 营业执照 / 户籍办理 / 税务五类。
- **许可**：`license = synthetic`，本地合成，无第三方授权约束，**可安全公开**。
- **规模**：300 条。
- **生成**：`generate_synthetic_gov.py`（确定性，固定种子 `SEED=4471`，重跑字节级一致）。
- **格式**：JSONL，Schema v1（见 [`../ALIGNMENT.md`](../ALIGNMENT.md)）。
- **状态**：原始输入态（`clean_text == raw_text`、`masked_text == raw_text`、`flags` 为空）。
- **内含构造样本**（用于演示任务二能力，全部明显虚构）：
  - 含假 PII：30 条（姓名 / 手机号 / 地址均为占位，演示脱敏）
  - 格式噪声：20 条（全半角标点混合、乱码、多余空白，演示清洗）
  - 精确重复：10 条（演示去重）
- **用途**：演示任务二在"教育之外"的领域同样可用；契合命题"教育、政务、工业等三类行业数据集"要求。
