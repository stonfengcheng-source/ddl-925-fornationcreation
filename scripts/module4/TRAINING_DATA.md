# 当前验证数据

默认原始候选数据为 `demo-datasets/education-synthetic/raw_5k.jsonl`，共 5000 条教育文本。网页按“每组样本数”和随机种子抽取 Raw 验证数据。

| 组别 | 当前输入 | 状态 |
|---|---|---|
| Raw | 5000 条原始教育文本 | 可生成、校验 |
| Rule | 尚无真实规则处理结果 | 留空，待接入 |
| LLM-only | 尚无真实质量评分结果 | 留空，待接入 |
| Data-Juicer | 尚无独立处理结果 | 留空，待接入 |
| Ours | 尚无真实规则与质量评价结果 | 留空，待接入 |

质量评价路径和 Data-Juicer 路径均可留空，等待队友提供实际输出。浏览器保存的旧人工样例路径（包括绝对路径）会清空，原始候选路径改用仓库教育原文；自行填写的其他路径保留。

旧人工样例不作为默认训练输入。重新生成训练配置时，只注册当前数据清单中的可用组。

生成的数据清单只在 `variants` 中登记可用组，其他组记入 `pending_variants`。校验、训练配置、模型运行及结果汇总按清单中的可用组执行，缺失组的历史文件或分数不参与本次验证。

例如每组样本数选择 100 时，生成的 Raw 数据位于 `experiments/module4/data/raw_100.jsonl`。这些数据副本和训练配置属于本地运行产物，不提交到 GitHub；其他电脑通过网页重新生成和校验。可以在网页调整样本数。
