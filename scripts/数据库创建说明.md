# 数据库说明（当前本地开发方案）

## 默认方案：SQLite

项目默认使用 `backend/data_task.db`，后端启动时会自动创建数据库文件和表，不需要安装 PostgreSQL，也不需要输入任何数据库密码。

```powershell
cd D:\PythonProject\clean\backend
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

## 在 PyCharm 中查看数据库

PyCharm 的 Database 工具与应用使用同一个文件：

1. 启动一次后端，生成 `backend/data_task.db`。
2. 打开 PyCharm 右侧 Database 窗口。
3. 点击 `+` → `Data Source` → `SQLite`。
4. 选择 `backend/data_task.db` 并测试连接。

注意：PyCharm 负责查看/执行 SQL，FastAPI 仍由 SQLAlchemy 根据 `DATABASE_URL` 建立运行时连接，二者不能共享 IDE 内部连接对象。

## 可选方案：PostgreSQL + pgvector

只有需要真实向量索引或部署环境统一使用 PostgreSQL 时才配置它：

```env
USE_SQLITE=false
DATABASE_URL=postgresql+psycopg2://postgres@localhost:5432/data_task_platform
```

PostgreSQL 是否要求密码取决于本机 `pg_hba.conf` 和用户配置。项目不再在代码、脚本或文档里写死数据库密码；如果本机 PostgreSQL 要求密码，请在本机环境或 PyCharm 数据源中按实际配置填写。

## 迁移和兼容

应用启动会执行 `create_all` 并补齐已有 SQLite 文件的新增字段。需要正式迁移流程时，在 `backend` 目录执行：

```powershell
.venv\Scripts\python.exe -m alembic upgrade head
```

pgvector 初始化脚本位于 `backend/scripts/init_pgvector.sql`，仅适用于 PostgreSQL。
