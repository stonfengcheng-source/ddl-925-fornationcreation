# 数据库创建说明

## 一句话说明

- **数据库（data_task_platform）**：需要您**手动创建一次**（按下面步骤做即可）。
- **表（比如 tasks）**：**不用您建**，只要数据库存在，启动后端时会**自动创建**。

---

## 您需要做的事（只需做一次）

### 第一步：确认已安装 PostgreSQL

- 已安装：打开 **cmd** 或 **PowerShell**，输入 `psql --version`，能看到版本号即可。
- 未安装：请先安装 [PostgreSQL](https://www.postgresql.org/download/windows/)，安装时记住您设置的 **postgres 用户密码**。

### 第二步：创建数据库（二选一）

**方式 A：用项目里的 SQL 文件（推荐）**

1. 在 **cmd 或 PowerShell** 里进入项目根目录，例如：
   ```bash
   cd d:\cursordata\data-task-platform
   ```
2. 执行（把 `postgres` 换成您的数据库用户名，如有需要）：
   ```bash
   psql -U postgres -f scripts/init-db.sql
   ```
3. 提示输入密码时，输入 postgres 用户的密码。
4. 看到 **CREATE DATABASE** 就表示数据库已经建好。

**方式 B：不用文件，直接输入一条命令**

1. 打开 **cmd 或 PowerShell**，输入：
   ```bash
   psql -U postgres
   ```
2. 输入 postgres 用户密码，进入 psql。
3. 在 psql 里输入下面这一行，回车：
   ```sql
   CREATE DATABASE data_task_platform;
   ```
4. 看到 **CREATE DATABASE** 即成功。输入 `\q` 退出 psql。

### 第三步：配置并启动后端

1. 在 `backend` 目录下复制 `.env.example` 为 `.env`。
2. 在 `.env` 里配置数据库连接，例如：
   ```env
   DATABASE_URL=postgresql://postgres:你的密码@localhost:5432/data_task_platform
   ```
   （把 `你的密码` 换成实际密码；如端口不是 5432，改成实际端口。）
3. 启动后端：
   ```bash
   cd backend
   venv\Scripts\activate
   uvicorn app.main:app --reload --port 8000
   ```

首次启动时，程序会**自动**在 `data_task_platform` 里创建 **tasks** 等表，无需再执行任何建表 SQL。

---

## 总结

| 谁来做 | 做什么 |
|--------|--------|
| **您** | 用 `scripts/init-db.sql` 或一条 `CREATE DATABASE` 命令，**手动创建数据库** `data_task_platform`（只需一次）。 |
| **程序** | 您启动后端后，**自动创建** tasks 等表。 |

`scripts/init-db.sql` 这个 SQL 文件的作用就是：**帮您执行“创建数据库”这一条命令**；表不用您建，交给后端即可。
